# CTF-2025 Challenges

Welcome to the **CTF-2025 Challenges** repository!

This repository contains a collection of Capture The Flag (CTF) challenges that I created for my college's CTF event. These challenges are designed to test and enhance your problem-solving skills in various domains of cybersecurity.

## Challenge Categories

The challenges are organized into the following categories:

- **Cryptography**: Decode and decrypt to find the hidden flags.
- **Reverse Engineering**: Analyze binaries to uncover secrets.
- **Web Exploitation**: Exploit vulnerabilities in web applications.
- **Forensics**: Investigate digital artifacts to extract information.
- **Miscellaneous**: Fun and creative challenges that don't fit into other categories.

## How to Use

1. Clone the repository:
    ```bash
    git clone https://github.com/your-username/CTF-2025.git
    ```
2. Navigate to the challenge directory of your choice.
3. Follow the instructions provided in the challenge's.
